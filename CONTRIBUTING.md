# Contributing to XRAR

We welcome contributions to XRAR!

## Guidelines
1. **Safety First**: Never bypass path sanitization in `xrar-filesystem`.
2. **License Compliance**: Only use permissively licensed crates (MIT, Apache-2.0, BSD).
3. **No Proprietary Code**: Do not copy reverse-engineered proprietary algorithms.
4. **Code Quality**: All pull requests must pass `cargo test --workspace` and `cargo fmt`.
5. **Localization**: When adding user-facing UI strings, update both `en.ts` and `ar.ts`.
